# Æther Weave AI Studio

**Æther Weave AI Studio** is a closed-source SaaS platform for AI-powered image and video generation and processing.

The platform gives users access to carefully prepared, production-oriented workflows while preserving advanced control over key pipeline settings. Users can achieve professional results without having to build complex node graphs or AI pipelines from scratch.

## What We Are Building

Æther Weave AI Studio is designed to provide:

- ready-made workflows for image and video generation;
- advanced access to generation and processing parameters;
- a streamlined interface for running complex AI pipelines;
- storage and management of user assets and generated media;
- scalable cloud infrastructure for computationally intensive workloads.

## GPU Compute

TensorDock is currently being evaluated as an on-demand GPU infrastructure provider for development, testing, AI inference, image generation, and video-processing workloads.

The evaluation is focused primarily on RTX 4090 and RTX 5090 instances, with attention to performance, reliability, cost efficiency, and suitability for future production workloads. TensorDock has not yet been selected as the final production provider.

## Cloud Storage

Backblaze B2 is planned as part of the platform's storage infrastructure for:

- user-uploaded source files;
- generated images and videos;
- workflow-related assets;
- selected model and processing artifacts;
- backups and long-term media storage.

The storage architecture is intended to scale with increasing numbers of users, generation jobs, and media assets.
